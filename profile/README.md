## 🌍 Présentation

**Rakonium** est un serveur Minecraft Java orienté **Survival MMORPG**.

Plonge dans un univers de survie où l'aventure, l'exploration et la progression sont au cœur de l'expérience.

Le serveur est actuellement en phase de **bêta test**. Cette période permet de tester les fonctionnalités, détecter les problèmes et améliorer l'expérience avant les prochaines étapes du développement.
